# AI Ustaz — фронтенд-прототип

Платформа для ИИ-генерации учебных материалов и обмена ими в сообществе преподавателей.
Это **только фронтенд**: никакого бэкенда, вся «генерация ИИ» — правдоподобная заглушка,
данные хранятся в `localStorage` браузера.

## Стек

- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4** (плагин `@tailwindcss/vite`)
- **React Router v7**

## Запуск

Нужен **Node.js 18+** (на текущей машине он не установлен — поставьте с https://nodejs.org).

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`.

Сборка продакшена: `npm run build`, предпросмотр сборки: `npm run preview`.

## Структура

```
src/
  components/      UI-примитивы, Navbar, WorkCard, ContextBuilder, MaterialRenderer, иконки
  hooks/           useTheme (светлая/тёмная тема)
  lib/
    generator.ts   демо-генератор: generateMaterial() и searchData()
    ollama.ts      РЕАЛЬНАЯ генерация через локальный Ollama (пока только флешкарты)
    store.tsx      глобальное состояние (Context + useReducer + localStorage)
    mockData.ts    стартовый набор работ и пользователей
    utils.ts       форматирование, справочники предметов/классов/заведений
  pages/           экраны приложения
  types.ts         доменная модель
```

## Языки и уровни

- Языки материала: **қазақша (основной)** и **русский**. Английский убран.
- Тип заведения: **Школа / Колледж / ВУЗ** — от него зависит список классов/курсов.

## Генерация через Ollama (локальный ИИ)

Пока по-настоящему через Ollama делаются **только флешкарты**. Остальные типы (тест, задание,
игра, план урока, конспект) делает демо-генератор. Расширяется в `src/lib/ollama.ts` по образцу
`generateFlashcards()`.

### Настройка

1. Установите и запустите [Ollama](https://ollama.com).
2. Разрешите браузеру обращаться к Ollama (CORS). В большинстве версий `localhost` уже разрешён;
   если панель в приложении показывает «нет подключения» — задайте переменную окружения и
   перезапустите Ollama:
   ```bash
   setx OLLAMA_ORIGINS "*"
   ```
3. Скачайте нужные модели (см. ниже).
4. В приложении: **Генератор → шаг «Что генерируем» → «Генерировать через Ollama»**. Там же
   задаётся своя модель под каждый язык и адрес сервера. Настройки хранятся в localStorage.

### Какие модели (бесплатные)

Технический момент: жёсткую JSON-схему в поле `format` мы **не** используем — на ней маленькие
локальные модели выдают заглушки вместо контента. Используется мягкий режим `format: "json"`
плюс пример в промпте.

| Язык | Модель по умолчанию | Команда | Комментарий |
| --- | --- | --- | --- |
| **Қазақша** | `hf.co/issai/Llama-3.1-KazLLM-1.0-8B-GGUF4` | `ollama pull hf.co/issai/Llama-3.1-KazLLM-1.0-8B-GGUF4` | **KazLLM** — национальная модель для казахского (ISSAI, Назарбаев Университет). Обучена именно на казахском, поддерживает kk/ru/en. Лучший бесплатный вариант. |
| Қазақша (запасной) | `gemma3:4b` | `ollama pull gemma3:4b` | Проверено: даёт связный казахский, изредка вставляет русское слово. Быстрая, ~4 ГБ. Семейство Gemma показывает сильный результат на бенчмарке KazMMLU. |
| **Русский** | `qwen2.5:7b` | `ollama pull qwen2.5:7b` | То, что использовалось на старом сайте. На русском работает хорошо, флешкарты выходят содержательными. |
| Русский (крупнее) | `qwen2.5:14b` / `gemma2:9b` | `ollama pull qwen2.5:14b` | Если хватает памяти — качество выше. |

Для казахского также есть 70B-версия KazLLM (`hf.co/issai/Llama-3.1-KazLLM-1.0-70B-GGUF4`) —
точнее, но требует мощного железа.

## Как подключить настоящий ИИ для остальных типов

Демо-генератор в `src/lib/generator.ts` (`generateMaterial()`, `searchData()`) заменяется на
вызовы API/Ollama — сигнатуры и формат `Material` менять не нужно, весь UI продолжит работать.
Для новых типов через Ollama — добавляйте функции в `src/lib/ollama.ts` рядом с
`generateFlashcards()` и подключайте их в `src/pages/Generate.tsx`.
